# 0.1.1 · 原生画板、文档版本与随手记

本次从 `develop` 的 [`bf6ca5d`](https://github.com/singous/orbis/commit/bf6ca5d5ac52c82e8659959324a6a787bccfd71f) 封版，源码保存在 [`release/axian-0.1.1`](https://github.com/singous/orbis/tree/release/axian-0.1.1)。暂不创建 0.1.1 tag 或 GitHub Release，也不合入 `main`。

## 本次变化

- **原生画板**：支持流程图、思维导图、系统架构、UML、ER 与泳道图，提供图形、模板、内置图标、图片、导入导出及正文引用；画板工作区增加交互式思维导图操作。
- **文档版本**：支持命名版本、自动历史、版本比较和恢复，Web、CLI 与 Agent 使用公共契约访问。
- **个人随手记**：提供工作空间内个人私有记录，支持富文本、附件、标签、搜索、置顶、回收站和本机草稿恢复。
- **多维表格**：支持正文内表格编辑与表单，改进网格显示、单元格输入、弹出层及触控操作。
- **界面与反馈**：更新 Orbis 品牌资源、登录与文集首页、目录导航、主题及焦点行为，统一使用 HeroUI Toast 提示操作结果。

## 升级前须知

旧版正文 `drawing` 绘图已在本次封版包含的开发改动中退役，不再提供旧编辑器、预览或数据下载。打开可编辑文档时，旧绘图块通过正常正文保存事务清除，其他正文内容与协同身份保留；新画板使用独立的原生模块。**仍依赖旧绘图的实例应先保留 0.1.0 环境与备份，评估该行为后再决定升级。**

数据库迁移已扩展至 `000027_quick_notes`，包含正文表格、原生画板、文档版本与随手记所需结构。本次封版只更新版本标识与文档，不新增或重写 SQL 迁移，也不执行部署或数据库迁移。

已有实例请按 [Compose 部署指南](../../deploy/README.md#已有-go-版本升级与备份) 备份配置、密钥、数据库与文件，核验迁移和协同引擎配置后再升级。数据回退需单独评估，不能仅替换旧镜像或用旧整库覆盖新增内容。

## 获取与构建

```bash
git clone --branch release/axian-0.1.1 https://github.com/singous/orbis.git
cd orbis

docker build --target server --build-arg ORBIS_VERSION=0.1.1 -t orbis-server:0.1.1 .
docker build --target frontend -t orbis-frontend:0.1.1 .
docker build --target collaboration -t orbis-collaboration:0.1.1 .
make cli-build
```

部署仍使用三个镜像的不可变引用，配置示例与启动步骤见 [部署指南](../../deploy/README.md)。CLI 与 Agent 协议保持 `2.0`，正文格式保持 `orbis.blocks.v1`；产品版本号与协议版本分别维护。
