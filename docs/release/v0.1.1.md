# v0.1.1 · 随手记、表格交互与文档体验

Orbis 0.1.1 改进日常记录与整理体验：用随手记捕捉想法，在文档内操作多维表格，展开嵌入内容时保留编辑状态，再通过新的首页和目录导航回到正在处理的内容。

封版标签为 [`release/v0.1.1`](https://github.com/singous/orbis/releases/tag/release/v0.1.1)，源码从 `develop` 的 `bf6ca5d` 建立发布分支，并包含发布期间合入的修复。本次交付源码与构建定义。

## 本次变化

- **个人随手记**：提供工作空间内个人私有记录，支持富文本、附件、标签、搜索、置顶、回收站和本机草稿恢复。
- **多维表格**：完善正文嵌入与展开操作，增加右键菜单、记录及字段拖拽排序；单击选择单元格，双击进入编辑，保留键盘输入与触屏操作。保存失败后可重试、导出或丢弃待保存改动。
- **文档编辑**：改进正文内画板、表格的显示与展开，保留编辑状态，完善未保存改动的离开确认、块操作、剪贴板和目录定位。
- **首页与导航**：更新欢迎首页、常用笔记本、最近访问、目录导航和加载占位，切换页面时保留工作空间布局。
- **界面与反馈**：更新品牌资源、登录页及控件样式，集中处理操作反馈；公开文档站的正文加载失败后可手动重试。

已有原生画板及正文引用继续保留。原生画板创建、文档分享、评论与版本面板、文档站导航及表格表单管理入口在本版暂缓开放，详见下方使用边界。

## 升级前须知

旧版正文 `drawing` 绘图已退役，不再提供旧编辑器、预览或数据下载。打开可编辑文档时，旧绘图块通过正常正文保存事务清除，其他正文内容与协同身份保留；新画板使用独立的原生模块。**仍依赖旧绘图的实例应先保留 0.1.0 环境与备份，评估该行为后再决定升级。**

数据库迁移扩展至 `000028_sheet_record_ordering`，包含独立及正文表格、原生画板、文档版本、随手记和表格记录排序所需结构。已发布的 SQL 迁移保持不变；发布源码和标签本身不会执行部署或数据库迁移。

已有实例请按 [Compose 部署指南](../../deploy/README.md#已有-go-版本升级与备份) 备份配置、密钥、数据库与文件，核验迁移和协同引擎配置后再升级。数据回退需单独评估，不能仅替换旧镜像或用旧整库覆盖新增内容。

## 获取与构建

显式检出标签，避免同名发布分支后续变化影响构建：

```bash
git clone https://github.com/singous/orbis.git
cd orbis
git switch --detach refs/tags/release/v0.1.1

docker build --target server --build-arg ORBIS_VERSION=0.1.1 -t orbis-server:0.1.1 .
docker build --target frontend -t orbis-frontend:0.1.1 .
docker build --target collaboration -t orbis-collaboration:0.1.1 .
make cli-build
```

部署使用三个镜像的不可变引用，配置示例与启动步骤见 [部署指南](../../deploy/README.md)。CLI 构建使用 `.go-version` 固定的 Go 工具链；CLI 与 Agent 协议保持 `2.0`，正文格式保持 `orbis.blocks.v1`，与产品版本分别维护。

## 验证

发布检查覆盖后端契约与 PostgreSQL/Redis 并发测试、独立 CLI、协同引擎、前端检查与构建、浏览器验收，以及 Docker Compose 安装与持久化重启。对应提交的结果见 [发布 PR 的 CI 检查](https://github.com/singous/orbis/pull/37/checks)。

## 使用边界

- 画板创建入口暂缓开放，已有画板及其正文引用保留。
- 文档分享、评论与版本管理面板、文档站导航以及表格表单管理入口暂缓开放；已有数据和 API 保留。CRDT 正文协同与自动保存、已有分享链接、公开文档站和公开表单读取继续可用。
- 自定义域名、API 调试台、高级站点模板、S3 存储适配与独立 MCP 服务尚未提供。
- 文档站中的外部 HTTP(S) 媒体仅固定 URL，不复制外部服务器上的文件。
