## v0.1.0 · 文档、协作与发布

Orbis 的首个封版版本，把个人记录、团队协作和对外文档站放进同一个工作空间。你可以整理文集与目录，和团队一起编辑文档，用多维表格管理结构化信息，再将选定内容发布为独立的文档站。

### 从一页文档开始

块编辑器支持富文本、普通表格、图片、附件、绘图和内容组件。文集分组与嵌套目录用于组织内容，搜索帮助找回资料；Markdown 导入导出让已有文档可以继续使用。

### 和团队一起完成

工作空间提供成员角色和邮件邀请。文档支持 CRDT 正文协同、自动保存、评论与历史恢复；多维表格支持字段、记录、视图、筛选、排序、分组、复制与撤销，也可导出为 CSV 或 Markdown。

### 准备好，再发布

文档站支持预览、显式发布、发布记录、版本切换与撤回，以及公开阅读、搜索、主题和移动端导航。每次发布固定内容快照，后续草稿编辑不会改变已发布版本。

临时共享可使用可撤销的实时分享；实时分享展示当前可见内容，使用时需留意未来新增或移入的文档范围。

### 接入 CLI 和 Agent

独立 Go CLI 与产品 Skill 通过公共 API 访问工作空间。Agent 令牌可限定工作空间和资源范围，支持持久化分块导入任务；CLI 可独立构建和分发。

## 开始使用

本次交付封版源码，包含服务端、Web 前端、协同引擎的 Docker 构建定义，以及 PostgreSQL、Redis 和应用服务的通用 Compose 模板。

## 已知限制

- 自定义域名、API 调试台、高级站点模板、S3 存储适配和独立 MCP 服务留待后续版本。
- 文档站中的外部 HTTP(S) 媒体仅固定 URL，不复制外部服务器上的文件。
- **浏览器端到端验收仍有失败待处理。** 封版提交已有的后端及 PostgreSQL 集成、Go CLI、协同引擎、前端检查和 Compose 部署验证均通过；本次未重新执行测试，详见 [CI 记录](https://github.com/singous/orbis/actions/runs/39458645821)。
